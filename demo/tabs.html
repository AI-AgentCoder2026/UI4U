ui-tabs

Keyboard-navigable tabs with automatic or manual activation. Try ← →, Home and End.

Overview. Panels are authored as light DOM — you write the <ui-tab> elements and the component owns roles, aria-* wiring, hidden state and tab order. Activity. Resize the window: padding and type scale up through container queries, while the tab list scrolls horizontally on narrow screens. Settings. Everything is themed through --ui4u-* custom properties. Override a token — do not fork component CSS.
