The author writes a plain <table>. The component keeps it and adds sorting, keyboard navigation and sticky headers.

  • Each sortable header contains a real <button>, so sorting works from the keyboard without re-implementing button semantics.
  • aria-sort is applied to exactly one header at a time, using ascending / descending / none.
  • A column marked data-type="number" compares numerically, and a formatted cell can carry data-value for the real number.
  • navigate is opt-in. A plain <table> is already navigable by a screen reader; grid roles and a roving tab stop are only added when you ask for cell-by-cell keyboard movement.
