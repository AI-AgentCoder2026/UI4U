ui-disclosure

One trigger and the content it reveals. The trigger is a real <button>, so it is keyboard reachable and announces its state through aria-expanded. Tab to it and press Enter or Space.

Variant

Authored markup is moved into a labelled region on connect and put back on disconnect, so the element can be re-parented without losing its content.

Panels are independent. Open one, close another — each keeps its own state.

Nesting works: the inner trigger is another native button inside the outer region, so tab order stays correct.

The solid variant drops the glass blur for denser interfaces.
