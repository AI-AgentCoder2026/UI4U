A radio with no group

Markup, options and theming. All three blocks are copyable.
  • Every option is a genuine <input type="radio">, themed with accent-color and given a real :focus-visible ring. The group shares one name, so the browser treats them as one native group.
  • The group renders a <fieldset> with a <legend> — that is the accessible name — and marks it role="radiogroup", so assistive technology announces one control to answer rather than a loose set of radios.
  • The group is one tab stop: the selected option, or the first enabled one, holds tabindex="0" and the rest hold -1. Arrow keys move and select, clamping at the ends; Home and End jump to the first and last; Tab is never prevented, so it leaves the group.
  • Disabled options are skipped by the arrow keys and can never hold the tab stop.
  • hint and error are chained through aria-describedby on the fieldset; an error sets aria-invalid, and required sets aria-required on both the fieldset and the native controls, so the form is actually blocked.
  • Every option row is at least 44px tall, so each is a comfortable touch target.
