ui-checkbox

A checkbox field that wraps a real <input type="checkbox">. Native focus rings, form submission and every assistive technology keep working, because the control is never re-rendered from a property — and the mixed state of a “select all” parent is a first-class option, not a painted imitation.

More

Markup, options and theming. All three blocks are copyable.
  • The control is a genuine <input type="checkbox">. It is themed with accent-color and given a real :focus-visible ring — never hidden behind a drawn box, which would break submission, mobile keyboards and screen readers.
  • The label is associated with for, and it contains text only. A label that wraps another control swallows its clicks, so it never does.
  • hint and error are chained through aria-describedby; an error sets aria-invalid, and required sets aria-required.
  • Every row is at least 44px tall, so the control and its label are one comfortable touch target rather than a 20px box.
  • indeterminate has no content attribute on the platform, so the component keeps its own attribute as the source of truth and mirrors it onto the control — in both directions.
  • readonly means what it says on a checkbox: the user cannot change the state, and the authored checked is the state that survives.
