UI4U

A framework-agnostic, mobile-first UI library. Vanilla ES6 modules, zero runtime dependencies, themed entirely through --ui4u-* custom properties. This index is itself built from the library — the table is a ui-tablegrid, the bar above it a ui-toolbar, and every control a ui-button.
