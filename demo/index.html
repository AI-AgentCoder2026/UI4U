UI4U

A framework-agnostic, mobile-first UI library. Vanilla ES6 modules, zero runtime dependencies, themed entirely through --ui4u-* custom properties. This index is itself built from the library — the catalogue below is a ui-cards grid, the bar above it a ui-toolbar, and every control a ui-button.

Each component ships with a demo, a unit suite and a browser smoke suite. Import the entry to register everything, or import a single component and call define() yourself.
