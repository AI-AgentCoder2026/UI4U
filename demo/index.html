UI4U

A framework-agnostic, mobile-first UI library. Vanilla ES6 modules, zero runtime dependencies, themed entirely through --ui4u-* custom properties.

  • ui-tabs Keyboard navigation, automatic + manual activation, three variants
  • ui-disclosure Collapsible sections, real button trigger, aria-expanded
  • ui-button Five variants, three sizes, loading and disabled states
  • ui-tooltip Hover and focus, automatic edge flipping, Escape to dismiss
  • ui-layout Resizable top/left/right/center/bottom, recursive
  • ui-popup Modal with a real focus trap, plus popover and drawer
  • ui-input Native input, label/hint/error wiring, validation surface
  • ui-tablegrid Column groups, sorting, search, pagination, cell navigation
  • ui-form Validation, error summary, focus the first invalid field
  • ui-sidebar Rail mode, arrow-key navigation, off-canvas drawer

Every component from the original roadmap has shipped. See the review for what to build next.

Each component ships with a demo, a unit suite and a browser smoke suite. Import the entry to register everything, or import a single component and call define() yourself.
